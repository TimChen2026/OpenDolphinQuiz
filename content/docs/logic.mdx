## Overview

The Logic tab renders the quiz as a **decision tree**, giving you a full view of the P1–P4 flow, and works together with the **input table** below for editing.

<img src="/docs/logic.png" alt="Logic decision tree" />

## Decision Tree

- Rendered with ECharts across the whole quiz
- Nodes are color-coded by level:

| Level | Color | Meaning |
|-------|-------|---------|
| P1 | Blue | First question |
| P2 | Orange | Branching questions |
| P3 | Green | Final choice (decides theme/manager) |
| P4 | Purple | Result page (no children) |

- Branches show the option label (e.g. `[A]`). Click a node to locate and edit it in the table below

## Editing with the Input Table

Below the tree is a **node content table** listing every node's questions and options:

- Click a tree node and the table scrolls to the matching row
- Edit question text directly in the table and save to the database
- Changes sync both ways with the **Interaction** editor

## Previewing Quiz Results

Below the table there is an **option box + Show button**:

1. Select a **P3 node**
2. Click **Show**
3. A phone-style preview of that node appears (identical to the Interaction preview)
