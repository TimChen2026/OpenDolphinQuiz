## What is DolphinQuiz?

DolphinQuiz is a **production-grade education trial-class sales funnel tool** designed for education institutions to capture, qualify, and convert trial-class leads. It includes everything you need: authentication, Quiz decision-tree builder, sales-funnel analytics, admin dashboard, and i18n support.

### Key Features

- **Authentication** — Email/password + Google OAuth via Better Auth
- **Quiz Funnel** — Decision-tree based Quiz to qualify trial-class leads
- **Analytics Dashboard** — Funnel conversion, node-level drop-off, and traffic-source attribution
- **Admin Dashboard** — User management, tenant isolation, role-based access control
- **Internationalization** — Full English and Chinese support via next-intl
- **Email System** — Transactional emails via Resend (verification, password reset, report notifications)
- **Marketing Pages** — Landing page, pricing, blog (MDX), legal pages

### Tech Stack

| Layer | Technology |
|-------|-----------|
| Framework | Next.js 16 (App Router) + React 19 |
| Styling | Tailwind CSS + Framer Motion |
| Database | PostgreSQL + Drizzle ORM |
| Auth | Better Auth |
