## What is DolphinQuiz?

DolphinQuiz is a **trial-class sales funnel management tool** built for education institutions. It uses a customizable Quiz decision tree to help you capture leads, invite prospects to trial classes, track inquiries, and follow up with sales — all in one place.

When a prospect completes your shared quiz link, the system automatically generates a **project number** and notifies your sales team. You can track each inquiry in the dashboard until it's won or closed.

## Core Flow

**Edit quiz → Generate link → Prospect answers → Project created & sales notified → Follow up / Won / Lost**

1. Edit quiz questions, options, and style in the **Interaction** tab
2. Check and generate the quiz link in the **Templates & Links** tab
3. Share the link with prospects; they complete the P1–P4 quiz
4. The system creates a project and sends an internal notification email; sales follows up in the **Project Board**

## Module Overview

| Module | Purpose |
|--------|---------|
| Project Board | View inquiry projects, move status between Follow-up / Won / Lost |
| Interaction | Edit quiz questions, options, and theme keywords with a phone preview; switch styles |
| Logic | View the quiz as a decision tree and edit node contents |
| Report Templates | Configure internal notification, Summary, and yellow/red warning email templates |
| Team | Manage sales director and sales managers, assign responsible themes |
| Email Settings | Set yellow/red warning trigger hours |
| Templates & Links | Use reference templates, check quiz info, generate and save links |
| Database | Search/export/edit project data, audit logs, and backups |
| Analytics | View traffic, theme, and sales performance charts |
