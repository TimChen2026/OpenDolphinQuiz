## 1. 注册与登录

访问网站首页，点击右上角**登录**或**注册**：

- 支持**邮箱 + 密码**注册，注册后需要验证邮箱
- 支持 **Google 账号**一键登录（首次登录需填写团队/机构名称）

登录后即可进入仪表盘。

## 2. 首次使用

新账户会自动生成一份**教育培训参考问卷**（含 P1–P4 完整决策树），无需从零搭建即可体验完整流程。

您也可以随时在**模板与链接**模块点击「使用参考模板」一键载入该问卷。

## 3. 四步上手

### 第一步：编辑问卷

进入**交互界面**，以手机预览方式修改问题与选项，为每个选项填写**主题词**，并选择问卷**风格**（Oxford 深蓝、Princeton 橙、MIT 科技等 7 种），点击「保存」与「确定」生效。

### 第二步：生成链接

进入**模板与链接**，点击「检查问卷信息」，通过后点击「生成链接」获得问卷链接，可复制分享给客户。

### 第三步：客户完成问卷

客户打开链接完成 P1→P2→P3→P4 问答，在结果页确认后，系统自动生成项目编号并发送**内部告知邮件**给对应销售经理。

### 第四步：跟进询盘

在**项目看板**查看新项目，跟进并将状态流转为**获单**或**失单**。

## 4. 套餐说明

| 套餐 | 说明 |
|------|------|
| 免费版 Free | 个人体验，1 个问卷、每月少量询盘额度 |
| 专业版 Pro | 中小团队，更多问卷与询盘额度，含完整数据分析 |
| 旗舰版 Max | 大型团队，最高配额与优先支持 |

> 具体配额与价格以 [定价页面](/pricing) 为准。询盘接近或达到上限时，项目看板顶部会显示升级提示。
