## DolphinQuiz 是什么？

DolphinQuiz 是面向教育机构的**试听课销售漏斗管理工具**。它通过一套可定制的 Quiz 决策树问卷，帮助机构完成客户获取、试听课邀约、询盘追踪和销售跟进的全流程管理。

客户通过您分享的问卷链接完成问答后，系统自动生成**项目编号**并通知销售团队，您可以在仪表盘中持续跟进，直到成交或关闭。

## 核心流程

**编辑问卷 → 生成链接 → 客户完成问答 → 生成项目并通知销售 → 跟进/获单/失单**

1. 在**交互界面**编辑问卷问题与选项，选择风格
2. 在**模板与链接**中检查信息并生成问卷链接
3. 将链接分享给潜在客户，客户完成 Quiz 问答
4. 系统生成项目并发送内部告知邮件，销售团队在**项目看板**跟进

## 功能模块一览

| 模块 | 用途 |
|------|------|
| 项目看板 | 查看询盘项目列表，流转跟进/获单/失单状态 |
| 交互界面 | 手机预览方式编辑问卷问题、选项与主题词，切换风格 |
| 逻辑界面 | 以决策树图查看问卷逻辑，编辑节点内容 |
| 报告模板 | 配置内部告知、Summary、黄/红色预警邮件模板 |
| 团队界面 | 管理销售总监与销售经理，分配负责主题 |
| 邮件设置 | 设置黄色/红色预警触发时长 |
| 模板与链接 | 使用参考模板、检查问卷信息、生成与保存链接 |
| 数据库 | 项目数据检索/导出/行内编辑，审计日志与备份 |
| 数据分析 | 查看访问量、主题、销售经理绩效等统计图表 |
