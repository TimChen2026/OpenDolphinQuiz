## 什么是 DolphinQuiz？

DolphinQuiz 是一个**生产级教育试听课销售漏斗工具**，专为教育机构设计，用于捕获、筛选和转化试听课线索。包含完整的用户认证、Quiz 决策树构建器、销售漏斗分析、管理后台和国际化支持。

### 核心特性

- **用户认证** — 邮箱密码 + Google OAuth（Better Auth）
- **Quiz 漏斗** — 基于决策树的 Quiz 用于筛选试听课线索
- **分析看板** — 漏斗转化率、节点级流失分析、流量来源归因
- **管理后台** — 用户管理、多租户隔离、基于角色的访问控制
- **国际化** — 完整的中英文支持（next-intl）
- **邮件系统** — 交易邮件（Resend）：验证、密码重置、报告通知
- **营销页面** — 首页、定价、博客（MDX）、法律页面

### 技术栈

| 层级 | 技术 |
|------|------|
| 框架 | Next.js 16 (App Router) + React 19 |
| 样式 | Tailwind CSS + Framer Motion |
| 数据库 | PostgreSQL + Drizzle ORM |
| 认证 | Better Auth |
| 邮件 | Resend |
| 国际化 | next-intl |
