## 界面说明

交互界面是**问卷编辑器**，以手机效果实时预览问卷，所见即所得。问卷由决策树节点组成，按层级分为 **P1 → P2 → P3 → P4（结果页）**。

> 📷 截图占位：将交互界面截图保存为 `public/docs/interaction.png`，并替换下方 `src` 路径即可显示。

<img src="/docs/interaction.png" alt="交互界面编辑器" />

## 编辑问题与选项

- 点击节点即可在手机预览中查看对应问题与选项（A/B/C/D）
- 修改问题文本或选项文本后点击**保存**，写入数据库
- 每个选项右侧提供**主题词**输入框，填写该选项对应的业务主题（如"少儿英语""成人雅思"），客户选择后将关联到该主题

## 选择问卷风格

交互界面下方提供风格模板供快速切换预览：

| 风格 | 说明 |
|------|------|
| Oxford 深蓝 | 白底卡片 + 主色按钮（默认） |
| Princeton 橙 | 暖橙主色 + 黑色衬线 |
| Yale 蓝 | 耶鲁深蓝 + 灰色辅色 |
| Stanford 红 | 斯坦福红 + 暖灰底色 |
| MIT 科技 | MIT 红 + 银灰辅色 |
| Harvard 深红 | 哈佛深红 + 黑白经典 |
| 跟随系统 | 随操作系统深浅色自动切换 |

选择风格后点击**确定**保存，生成的问卷链接与客户看到的问卷将应用该风格。

## 保存机制

- 节点内容修改：点击「保存」立即写入数据库
- 风格选择：点击「确定」保存到会话，供链接生成使用
- 修改后建议到**模板与链接**重新执行检查再分享新链接
